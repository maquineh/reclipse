# M2 — Fundação semântica Java

Status: **fundação entregue**. O M2 completo (inferência de tipos, completion de membros, referências, refactors e diagnósticos semânticos equivalentes ao JDT) continua em andamento.

## Entregue

### Resolução de classpath

Novo crate `reclipse-classpath`:

- **Eclipse** `.classpath`:
  - source entries;
  - bibliotecas (`kind="lib"`);
  - JRE container detectado separadamente;
  - avisos para containers/variáveis/projetos externos não resolvidos.
- **Maven** (`pom.xml`):
  - dependências diretas;
  - propriedades (`${...}`, `project.version` etc.);
  - repositório local `M2_REPO` ou `~/.m2/repository`;
  - `sourceDirectory`/`testSourceDirectory`.
- **Gradle**:
  - coordenadas `group:artifact:version` em `build.gradle`/`.kts`;
  - busca no repositório Maven local;
  - JARs em `lib/` e `libs/`.
- **JDK**:
  - `RECLIPSE_JDK`, `JAVA_HOME` e instalações comuns;
  - JDK 9+ via `jmods/*.jmod`;
  - JDK 8 via `rt.jar`;
  - seleção pela maior versão instalada.
- Dependências transitivas, exclusions e BOMs ainda não são resolvidos.

### Índice nativo de classes

- Leitor de `.class` próprio, sem JVM:
  - constant pool;
  - tipo/classe, superclasse, interfaces;
  - campos e métodos públicos/protegidos;
  - descritores convertidos para assinaturas legíveis (`String name`, `int size()`);
  - origens (JAR/JMOD).
- Indexação de JARs com `zip` e JMODs (header de 4 bytes + ZIP).
- Deduplicação de classes e mapa de nomes simples.
- Índice do JDK 25 local: **70 JMODs, 26.862 classes, 15.220 tipos públicos, ~1,7 s** em release.

### Camada semântica inicial

`reclipse-java::semantic`:

- `ProjectTypes`: FQN, localização e nomes simples de tipos do projeto.
- Resolução de tipos por:
  - import explícito;
  - mesmo pacote;
  - import wildcard;
  - `java.lang`;
  - nome simples único no projeto/classpath.
- Diagnóstico de **imports não resolvidos**, com linha.
- Lista de candidatos para completion de tipos.
- Inferência local simples (`Type var = ...`) para futura completion de membros.

### UI

- Status do classpath na barra inferior:
  - progresso de archives;
  - quantidade de archives/classes e tempo;
  - falhas com tooltip.
- **Open Type** (`Ctrl+Shift+T`) agora inclui tipos do classpath/JDK.
- **F3** em um tipo importado do classpath abre o **visualizador de tipo externo**:
  - FQN, tipo, pacote, origem, superclasse/interfaces;
  - campos e métodos públicos, com assinaturas;
  - aviso de que o fonte não está disponível.
- Painel de **Problemas** mostra imports não resolvidos (amarelo) além dos erros de sintaxe.
- O demo resolve `java.util.List`, `java.util.stream.Collectors` e os tipos do projeto com o JDK local.

## Limitações

- Maven/Gradle: apenas dependências diretas; sem transitivas, exclusions, classifiers complexos, BOMs ou perfis.
- Sem download de dependências; usa apenas o repositório local.
- Sem sources/Javadoc anexados.
- JDK escolhido pela maior versão instalada, não pelo `release`/`source`/`target` do projeto.
- Classpath não é observado em tempo real; reindexar o projeto recarrega.
- Sem inferência de tipos completa, generics, overload resolution ou completion de membros inline.
- Sem find references/rename; sem diagnostics do javac/JDT.
- Tipos do classpath abrem metadados, não código-fonte.
- Sem suporte a Android/Kotlin/Gradle tooling API.
